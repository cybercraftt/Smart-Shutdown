# 💻 Smart Shutdown

**Smart Shutdown** - утилита для Windows, которая отслеживает сетевую активность компьютера и автоматически выполняет выбранное действие после завершения загрузок или снижения сетевого трафика.

Программа может автоматически:

* выключить компьютер;
* перевести компьютер в сон или гибернацию;
* перезагрузить компьютер;
* выполнить действие через заданный таймер безопасности;
* показать уведомление звуком;
* работать в системном трее;
* сохранять пользовательские настройки;
* использовать несколько языков интерфейса.

> ⚠️ Программа управляет системными действиями Windows. Перед использованием проверьте выбранные параметры и убедитесь, что важные файлы сохранены.

## 🌟 Возможности

### 📡 Мониторинг сетевой активности

Smart Shutdown отслеживает текущую скорость передачи данных через сетевые интерфейсы компьютера.

Доступны два направления мониторинга:

* **Upload** - отдача данных;
* **Download** - загрузка данных.

Когда скорость сети опускается ниже установленного порога на заданное время, программа определяет снижение активности и запускает выбранное действие.

### ⚙️ Настраиваемый порог скорости

Можно указать порог сетевой активности, ниже которого программа будет считать соединение неактивным.

Например:

```text
Порог: 300 KB/s
Время простоя: 60 секунд
```

Если скорость сети остается ниже заданного значения в течение указанного времени, запускается действие для компьютера.

### 🖥️ Действия с компьютером

Программа поддерживает следующие действия:

* **Завершение работы**;
* **Сон / Гибернация**;
* **Перезагрузка**.

Перед завершением работы, сном или перезагрузкой Windows используется задержка безопасности.

### ⏱️ Таймер безопасности

Встроенный таймер безопасности позволяет выполнить выбранное действие через заданное время независимо от текущего сетевого трафика.

Таймер можно отключить.

```text
0 - таймер отключен
```

Это удобно, если загрузка зависла, сеть перестала передавать данные или требуется принудительно завершить работу компьютера через определенное время.

### 🔊 Звуковое уведомление

После завершения мониторинга и перед выполнением действия программа может использовать звуковое уведомление.

Звуковое оповещение можно включать или отключать в настройках.

### 📌 Работа в системном трее

При наличии необходимых дополнительных библиотек Smart Shutdown может сворачиваться в системный трей.

Из трея доступны действия:

* развернуть окно;
* завершить работу программы.

### 💾 Сохранение настроек

Пользовательские параметры сохраняются в файл:

```text
window_config.json
```

Сохраняемые настройки включают параметры окна и настройки работы программы.

## 🚀 Установка и запуск

### 1. Скачайте проект

Склонируйте репозиторий:

```bash
git clone https://github.com/cybercraftt/Smart-Shutdown.git
```

Перейдите в папку проекта:

```bash
cd Smart-Shutdown
```

Или скачайте архив проекта через кнопку:

```text
Code → Download ZIP
```

Распакуйте архив в удобную папку.

---

### 2. Установите зависимости

Откройте командную строку в папке проекта и выполните:

```bash
pip install -r requirements.txt
```

Если команда `pip` не работает, используйте:

```bash
python -m pip install -r requirements.txt
```

---

### 3. Запустите программу

```bash
python smart_shutdown.py
```

После запуска откроется графический интерфейс Smart Shutdown.

| Библиотека      | Назначение                                |
| --------------- | ----------------------------------------- |
| `psutil`        | Получение информации о сетевой активности |
| `customtkinter` | Современный графический интерфейс         |

## ⚙️ Как пользоваться

### Шаг 1. Запустите программу

Откройте Smart Shutdown через Python или собранный EXE-файл.

### Шаг 2. Выберите направление трафика

Выберите, какую активность отслеживать:

* отдачу данных;
* загрузку данных.

### Шаг 3. Установите порог

Укажите допустимую скорость сети.

Например:

```text
300 KB/s
```

### Шаг 4. Укажите время простоя

Установите, сколько секунд скорость должна оставаться ниже порога.

Например:

```text
60 секунд
```

### Шаг 5. Выберите действие

Доступны:

* завершение работы;
* сон / гибернация;
* перезагрузка.

### Шаг 6. При необходимости включите таймер безопасности

Укажите время, через которое действие будет выполнено независимо от сетевой активности.

Если указать:

```text
0
```

таймер будет отключен.

### Шаг 7. Запустите мониторинг

Нажмите кнопку запуска автоматического мониторинга.

Программа начнет отслеживать сетевую активность.

### Шаг 8. Отмена действия

Если действие уже запланировано, используйте кнопку:

```text
ОТМЕНИТЬ ДЕЙСТВИЕ ПК
```

## 🛡️ Отмена запланированного действия

Перед системным действием Windows используется задержка.

Если действие было запущено ошибочно, его можно отменить через кнопку отмены в интерфейсе программы.

Для системных действий Windows используется команда отмены запланированного действия:

```text
shutdown /a
```

> Примечание: отмена зависит от типа действия и текущего состояния Windows.

## ❗ Возможные проблемы

### Ошибка: `python is not recognized`

Если появляется ошибка:

```text
'python' is not recognized as an internal or external command
```

Возможно, Python не добавлен в PATH.

Решение:

1. Переустановите Python.
2. На первом экране установки включите:

```text
Add Python to PATH
```

3. Завершите установку.
4. Перезапустите командную строку.

---

### Ошибка: `pip is not recognized`

Попробуйте использовать:

```bash
python -m pip install -r requirements.txt
```

---

### Ошибка отсутствующей библиотеки

Если появляется сообщение вида:

```text
ModuleNotFoundError
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Или установите конкретную библиотеку:

```bash
pip install psutil
pip install customtkinter
pip install pystray
pip install pillow
```

---

### Не работает системный трей

Функция системного трея зависит от дополнительных библиотек:

```text
pystray
pillow
```

Установите их:

```bash
pip install pystray pillow
```

После установки перезапустите программу.
